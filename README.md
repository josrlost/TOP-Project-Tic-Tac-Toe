# TOP-Project-Tic-Tac-Toe
The objective of this project from TOP, from the JavaScript curriculum, was to create a functional Tic Tac Toe game.
The focus of this project was to keep the global namespacing of the project at the minimum, with using global
variables as little a possible. Also, the focus of the project was to learn and to implement Immediately Invoked Function
Expressions, to simulate modules. Use function factories to create objects, as well as making use of private variables.
My personal goal was to created the whole tic tac toe game within a one single global variable that would have the
whole local environment within an IIFE.
